# Dream11 Cricket Predictor

Streamlit deployment version of the Dream11 cricket ML predictor.

## Features

- Upcoming match lookup through Cricbuzz
- Confirmed Playing XI support
- Full squad fallback when Playing XI is not announced
- Manual squad prediction
- Historical match prediction
- Player identity matching
- Venue identity matching
- T20, ODI, Test and Hundred ranking models

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Deploy `app.py` from the root of the GitHub repository using Streamlit Community Cloud.
